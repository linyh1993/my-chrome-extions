关于

X Suite

仅面向 X（Twitter）。勿同时加载 archive/legacy-extensions/ 下的旧扩展。

权限说明

  • storage：保存过滤规则、记录库与镜像设置。
  • debugger（可选）：仅在手动开启流量镜像时按需申请并附加到当前标签页。
  • sidePanel / tabs：侧边栏控制镜像与选项页导航。
