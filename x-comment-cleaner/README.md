# X 垃圾评论拦截助手 (X Spam Reply Cleaner)

一个独立、轻量、高效率的 Chrome 扩展（Manifest V3），专为拦截和折叠 X (Twitter) 帖子下方泛滥的黄推、引流号、Bot 复制粘贴刷屏等垃圾评论。

---

## 🌟 核心特性

1. **智能识别过滤**：
   - **关键词匹配**：内置常见黄推引流词库（如「比她好看」、「没她骚」、「看主页」、「进群」、「门槛」等），支持自定义添加/删除。
   - **纯数字 / 随机单数字刷屏过滤**：自动识别并折叠仅包含数字（如 1、5、8、666 等）的占楼灌水与刷权重 Bot 评论。
   - **Bot 引流特征模式识别**：自动识别「引导语 + @引流账号 + 尾随随机数字/Emoji」的典型刷屏脚本。
   - **同帖重复刷屏过滤 (Copypasta)**：同一推文下，若有多个账号发送雷同文案，自动判定为垃圾脚本并拦截。
2. **灵活呈现**：
   - **折叠占位模式（默认）**：折叠并显示小巧提示条（标明拦截原因），点击即可随时展开，防止误判。
   - **完全隐藏模式**：彻底隐藏 DOM，还你清爽评论区。
3. **安全与性能**：
   - 基于原生 JavaScript + CSS，无外部依赖。
   - 采用防抖 `MutationObserver` 监听 SPA 无感流式加载，零性能损耗。
   - 绝不收集或上传任何个人数据，全部配置保存在本地浏览器 `chrome.storage`。

---

## 🚀 安装使用指南

1. 打开 Chrome 浏览器，访问 `chrome://extensions`。
2. 打开页面右上角的 **「开发者模式」** (Developer mode) 开关。
3. 点击左上角的 **「加载已解压的扩展程序」** (Load unpacked)。
4. 选择当前扩展目录：`x-comment-cleaner`。
5. 打开任意 [X (Twitter)](https://x.com) 帖子详情页，即可自动生效！点击扩展图标可打开设置面板自定义黑名单与模式。
