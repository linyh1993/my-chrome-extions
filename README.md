# my-chrome-extions

个人 Chrome 扩展项目集合。所有扩展均按 Manifest V3 编写。

## 活跃项目

| 目录 | 说明 |
|------|------|
| [`omni-relay/`](omni-relay/) | **推荐安装**：通用多平台（X, Reddit 等）数据与流量中继器 |
| [`x-comment-cleaner/`](x-comment-cleaner/) | **推荐安装**：X 垃圾评论与引流 Bot 拦截助手（独立扩展） |

## 归档项目

| 目录 | 说明 |
|------|------|
| [`archive/legacy-extensions/`](archive/legacy-extensions/) | 已归档的历史独立扩展快照（`x-suite`, `reddit-scraper-extension`, `x-comment-filter`, `traffic-relay`，勿加载） |
| [`archive/inactive-projects/`](archive/inactive-projects/) | 已停用的历史独立项目（`traffic-relay`, `chrome-capture-toolkit`，默认勿读） |
